# Reference: Vibe Coding Explained — Google Cloud
**Source:** https://cloud.google.com/discover/what-is-vibe-coding
**Date:** March 2026
**Key Points:**

- Term coined by AI researcher Andrej Karpathy in early 2025
- Shifts primary role from writing code line-by-line to guiding AI assistant
- Two main applications: "Pure" vibe coding (exploratory) and Responsible AI-assisted development (professional)
- Vibe deploying: Launch app to production with single click or prompt
- Google tools: AI Studio (beginner), Gemini Code Assist (IDE), Gemini CLI (terminal), Antigravity (autonomous agents), ADK (custom agents)
- Comparison table: Traditional programming vs. vibe coding on code creation, role, expertise, input, speed, error handling, learning curve, maintainability
- Key feature: GEMINI.md file acts as "long-term memory" for project context
- MCP (Model Context Protocol) servers extend AI capabilities
