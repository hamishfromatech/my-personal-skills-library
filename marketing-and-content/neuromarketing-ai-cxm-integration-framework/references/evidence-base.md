## Framework Architecture

### The Two Journeys

**Customer Journey** (Lemon & Verhoef 2016 extension):
- Pre-purchase: Need recognition → Information search → Evaluation of alternatives
- Purchase: Choice → Transaction → Payment
- Post-purchase: Consumption → Satisfaction/dissatisfaction → Loyalty/advocacy

**Firm Journey** (Holmlund et al. 2020 + Schmitt 2003 extension):
1. Data Collection (neuroscientific methods)
2. Analytics (AI-enabled: descriptive, predictive, diagnostic, prescriptive)
3. Insights (emotional, cognitive, behavioral)
4. Touchpoint Actions (monitoring, prioritization, adaptation, journey design)

### The AI Horizontal Cross-Section (Huang & Rust 2021)
- Mechanical AI: Automate repetitive tasks (data scraping, segmentation)
- Thinking AI: Process data for conclusions (NLP categorization, recommendations)
- Feeling AI: Analyze emotional interactions (affective computing, sentiment analysis)

## The Two Novel Mechanisms

### Mechanism 1: In-situ Affective/Attentional Inference
Neuro/biometric signals allow AI systems to infer affective and attentional states at the moment of customer-firm interaction, rather than retrospectively from purchase or clickstream data. This is the temporal advantage: real-time state assessment vs. post-hoc behavioral inference.

### Mechanism 2: Psychophysiological-to-Managerial-Action Mapping
These inferences can be mapped onto specific managerial actions — touchpoint monitoring, prioritization, adaptation, and journey design — creating a more direct link between psychophysiological signals and firm-level decisions than existing behavioral-data frameworks provide.

## The Privacy-First Behavioral Proxy Translation

The A-Tech adaptation translates each neuro/biometric signal to a privacy-preserving behavioral proxy that can be computed on-device:

### Translation Principles
1. **Signal preservation**: The behavioral proxy must capture the same underlying cognitive/affective construct
2. **On-device computation**: All proxy computation occurs locally; only aggregated, consented metrics leave the device
3. **User control**: Users can inspect, export, and delete their behavioral proxy data
4. **No biometric collection**: No EEG, eye-tracking, GSR, or facial coding data is collected from users
5. **Validation thesis**: The behavioral proxies are theoretically grounded in neuroscience literature but require empirical validation against biometric baselines

### Proxy Validation Framework
For each proxy, the validation question is: does the behavioral signal correlate with the neuro/biometric signal that would be measured in a lab setting?

This validation is future work. The current framework provides the theoretical mapping; empirical validation requires controlled studies comparing behavioral proxies to biometric measurements.

## Ethical Framework

The framework should be applied with attention to:
1. Informed consent (consumers understand data collection and use)
2. Transparency (firms explain AI inference processes)
3. Data minimization (collect only necessary signals)
4. Consumer choice (opt-out without service loss)
5. Algorithmic accountability (safeguards against manipulation)
6. Vulnerability protection (special protections for susceptible populations)

These principles should be considered throughout the firm journey, from data collection and analysis to insight generation and action.
