# GitHub Copilot Consumption Shift Case Study

## Source
GitHub Blog / Industry analysis (2025)

## The Shift
GitHub moved Copilot from pure seat-based pricing to a hybrid consumption model:

### Before (2024)
- $19/month per seat (individual)
- $39/month per seat (business)
- Flat fee, unlimited usage within seat

### After (2025)
- Base seat fee retained
- AI credit bundles added for advanced features
- Credits consumed by:
  - Copilot Chat interactions
  - Code generation volume (beyond baseline)
  - Multi-file refactoring operations
  - Agent-mode orchestration

### Credit Mechanics
- Monthly credit allocation per seat tier
- Unused credits roll over up to 2 months
- Overage at 1.5x base credit rate
- Real-time dashboard showing consumption

### Why It Works
- Captures value from power users without penalizing light users
- Credits feel like currency — users make conscious tradeoffs
- Roll-over reduces anxiety about "wasting" credits
- Overage pricing is punitive enough to encourage tier upgrades

### Challenges
- Users initially confused by credit system
- Required extensive in-product education
- Some enterprise customers demanded unlimited tiers (offered at premium)

## A-Tech Lessons
1. Credit systems require significant UX investment
2. Roll-over caps prevent hoarding while reducing anxiety
3. Real-time dashboards are non-negotiable for consumption pricing
4. Always offer an "unlimited" enterprise tier for large accounts
