# Skill: AI Agent Business Models

## Summary
AI agents represent a fundamental shift from "copilot" assistants to autonomous actors that execute entire workflows independently. This enables new pricing models tied to tangible ROI, workflow completion, and cost savings rather than per-seat SaaS subscriptions.

## Copilot vs. Agent vs. Service

| Model | Role | Pricing | Example |
|-------|------|---------|---------|
| **Copilot** | AI sidekick; human in the loop | Per seat, consumption | GitHub Copilot, Abridge |
| **Agent** | Autonomous; executes workflows | Outcome, workflow, ROI-based | Intercom Fin ($0.99/resolution) |
| **AI-Enabled Service** | Automation + human oversight | Per output, market rate | EvenUp (per demand letter) |

## Agent Pricing Strategies
1. **Outcome-Based**: Charge per successful result (ticket resolved, lead generated, claim processed)
2. **Workflow-Based**: Charge per completed task (meeting booked, contract drafted)
3. **Cost-Equivalent**: Charge based on cost of hiring equivalent human FTE
4. **Hybrid**: Platform fee + outcome credits that scale with usage

## Key Insight
Agents decouple output from human headcount. Pricing should reflect work completed, not access granted. Every major software revolution rewrites value capture: client-server monetized licenses, SaaS monetized access, AI monetizes outcomes.

## The 7 AI Systems Framework (Practical Income Models)
1. **Resume Tailor** — $50-$250/client; Flask + OpenAI API
2. **Video Summarizer** — ~$120/month passive via ads; Streamlit
3. **Email Writer** — $400-$600 freelance; Gmail API + GPT-4
4. **Product Description Generator** — $700+ per Shopify integration
5. **Document Search SaaS** — $15/month/user; embeddings + similarity search
6. **Social Media Assistant** — $99/month/service; scheduled AI content
7. **Business Idea Generator** — Viral free tool + ads/affiliate monetization

## Implementation Steps
1. Identify a repetitive workflow where human time is currently required
2. Break workflow into discrete, automatable steps
3. Build agent with open-source models + orchestration framework
4. Define unambiguous success metric for the workflow
5. Price at 10-20% of human cost or 30-50% of value created
6. Start with narrow scope, expand as agent proves reliability
7. Build "human-in-the-loop" fallback for edge cases

## Key Metrics
- Task completion rate (autonomous vs. human-assisted)
- Cost per outcome vs. human equivalent
- Accuracy / quality score
- Time to completion (agent vs. human)
- Customer expansion rate (natural usage growth)
- Unit economics: gross margin per outcome
