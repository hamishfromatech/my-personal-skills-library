# Agency Argument Sources

## Primary Sources

1. **Joost de Valk** — "The agency case for open source" (joost.blog, April 24 2026, updated June 11 2026)
   - Original essay establishing the agency argument framework
   - Adam Smith/David Ricardo cost-of-production framing
   - Five historical analogies (printing press, handloom weavers, enclosure, electrification, guilds)
   - Four agency properties and honest self-critique

2. **Dries Buytaert** — quoted January 2026
   - "The only software you can run without permission... No vendor, no government, and no sanctions regime can ever take it away."

3. **Amanda King** — "Who Watches the Watchmen?"
   - Stanford/Princeton Foundation Model Transparency Index data
   - Meta dropped from 60 to 31; Mistral dropped 37 points; average fell from 58 to 40
