## Research Phase Summary

### Behavioral Psychology & Nudging

**Key finding:** The "nudging to boosting" shift (Hertwig et al., 2025, *Behavioural Public Policy* 9(4):874-885, CC BY) represents the most significant paradigm-level development in applied behavioral science since Thaler & Sunstein's original nudge concept (2008). The paper argues that the deficit model underlying nudging — which leverages or works around human biases — is insufficient for the complex, collective challenges facing society. The alternative "boosting" approach builds people's competences to make informed choices, with proven interventions across digital literacy, risk literacy, financial literacy, statistical reasoning, health literacy, and decision-making.

**Novel vs. incremental:** NOVEL. The existing skill library has 8+ nudging skills (nudge-theory-choice-architecture, digital-nudging-ethical-persuasion, hyper-nudging-ai-personalization-ethics, nudge-disclosure-transparency-effectiveness, nudge-invisibility-metacognitive-miscalibration, nudging-mental-health-evidence-synthesis, co-designed-digital-nudging, gap-behavioral-science-framework). None address the boosting paradigm as a distinct approach. The GAP framework (Nature 2026) touches on AI augmentation of behavioral tools but doesn't present the competence-building alternative. This is a new paradigm, not an incremental finding.

**A-Tech alignment:** Boosting directly serves A-Tech's values of financial freedom (financial literacy boosts), practical implementation (durable competence over one-time steering), and open-source philosophy (self-nudging = citizen choice architecture = user empowerment). It is the structural antidote to hyper-nudging and cognitive surrender.

### Developer Experience & Vibe Coding

**Key finding:** The Cloud Security Alliance (June 2, 2026) published the first systematic analysis of the "vibe coding governance gap" — the finding that NONE of the major AI security frameworks (NIST AI RMF, OWASP LLM Top 10, CSA MAESTRO, CSA AICM) provide guidance for citizen developers building AI-powered applications without professional security oversight. Empirical evidence is alarming: 0 of 5,600 scanned vibe-coded apps had basic security controls; AI-generated code exposes secrets at 2x the rate of human code; CVEs from AI-generated code are accelerating (6→15→35 in Q1 2026). Unit 42's SHIELD framework (Jan 2026) provides the first actionable control set: Separation of duties, Human in the loop, Input/Output validation, Enforce helper models, Least agency, Defensive controls.

**Novel vs. incremental:** NOVEL as a governance/systems-level analysis. The existing vibe-coding and vibe-coding-security-defense skills address individual practices. The new skill addresses the structural governance gap, the framework inadequacy, the citizen developer persona, and the SHIELD framework as a complete control set. The documented breaches (Moltbook, Cal AI, Lovable CVE-2025-48757) are new evidence. The CSA recommendations (tiered governance, citizen-developer governance track, platform vendor responsibility) are new frameworks.

**A-Tech alignment:** Direct competitive moat for A-Coder — "the AI coding tool that doesn't ship vulnerabilities." SHIELD-compliant architecture is a market-positionable differentiator. The open-source security judge agent creates ecosystem leverage. Connects to comprehension-debt-framework, calm-technology-ai-coding, and boosting (building security review competence).

### Agentic AI Workflows & Trust Protocols

**Key finding:** The agentic trust ecosystem has crystallized in 2026 around five major protocols that are converging through the FIDO Alliance standards process:
- Visa Trusted Agent Protocol (Oct 2025) — agent-merchant trust via cryptographic signatures
- FIDO Alliance Agentic Authentication Standards (April 2026) — open standards for agent authentication, with Google AP2 and Mastercard Verifiable Intent as founding contributions
- Experian Agent Trust / KYA (April 2026) — human-to-agent identity binding
- Akamai Agentic Security Framework (June 2026) — security infrastructure for agent traffic
- Mastercard Agent Pay + Verifiable Intent (June 2026) — card-network tokenization for agents

**Novel vs. incremental:** PARTIALLY NOVEL. The existing skill library has agentic-payments-protocol-ap2, agent-pay-card-network-integration, agent-reputation-identity-framework, agentic-commerce-trust-design, and agentic-payments-compliance-2026. These cover individual protocols. The new skill is novel in three ways: (1) it maps the full 2026 protocol ecosystem and their convergence through FIDO, (2) it introduces the KYA (Know Your Agent) framework as an emerging standard pattern, and (3) it provides the trust stack architecture showing how all protocols fit together. The FIDO Alliance's role as the standards home and the specific contributions (AP2, Verifiable Intent) are new developments since the existing skills were created.

**A-Tech alignment:** A-Tech can be the open-source, privacy-first implementer of this trust stack. Contributing reference implementations to FIDO creates ecosystem leverage. Agent trust built into A-Coder marketplace is a competitive differentiator. The privacy-first design of FIDO standards (phishing-resistant, credential-free delegation) aligns with A-Tech's core values.

The three new skills form a coherent narrative:

1. **Boosting** provides the behavioral science paradigm — build competence, not just steer behavior.
2. **Vibe Coding Governance Gap** applies this to code security — the environment must be secure-by-default (SHIELD) while building the developer's security review competence (boosting).

The common thread: **environmental guardrails (nudges/SHIELD/protocols) + competence building (boosts) = durable, autonomous, trustworthy systems.**
