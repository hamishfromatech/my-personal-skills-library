## 1. Research Summary

This run opens cycle 24 (new calendar day in Pacific/Auckland after cycle-23 run-1/run-2 completed on Sept 11). The Sept 9–12 window produced one dominant theme — **the consumer agent + answer-surface governance wave** — plus two precision updates the library lacked. Four selections passed grep dedup; the headline clusters:

1. **The isolation spectrum completed at the top tier.** Meta's Muse launch (Sept 8) ships the first consumer personal agent with a **dedicated cloud Secure VM containing a system-level-isolated Sentinel agent that gates every outbound request** — nothing Muse does reaches the internet without Sentinel approval, credentials are stored where Muse can use them without seeing them, and Stripe Link issues one-time-use virtual cards. This lands as the cloud-VM-gated tier of the library's consumer-isolation ladder, between PlugClaw (hardware, $149, cycle 18) and Violoop (device-held memory + physical approval button, cycle 21), and it converts "agent permissions" from a prompt/checkbox problem into a **second-process problem**.
2. **The answer-surface conflict-of-interest pattern landed.** One week after ChatGPT Ads hit a $1B annualized run rate (already a skill, cycle 20), OpenAI **quietly barred competitor image/audio-generation tools from advertising on ChatGPT and removed organic links/citations for photo editors and image generators** — pulling Adobe's Firefly ads with no public notice — while launching ChatGPT Images 2.5 and Live voice in the same window (The Information via Cryptonomist, Sept 10). This is the broadcast-network rival-lockout pattern re-appearing on an answer surface, with weaker disclosure norms.
3. **Open-weight ARR velocity calibrated.** Moonshot AI told investors it targets **$2B annualized revenue by year-end** (Bloomberg/TechCrunch, Sept 11) — ARR $300M (June) → $1B (Aug) → $2B target (Dec), a 3.3× two-month jump on the K3 release. Peers: Z.ai $1.6B, MiniMax $800M (Aug). Calibration: ~3% of Anthropic's $65B / ~5% of OpenAI's $40B — the open-weight thesis is velocity per development dollar, not parity. The Anthropic distillation allegations (Sept 8–11) are the governance counterweight to the same company.
4. **The FL/DP shelf gained an exactness + honesty artifact.** Chorus (Apache-2.0, pip chorus-fl) implements FedEx-LoRA **exact federated LoRA aggregation** (naive FedAvg is mathematically broken for LoRA: avg(B@A) ≠ avg(B)@avg(A); SVD residual folding each round makes it exact) with an opt-in stateful DP accountant — and ships `docs/honest-tradeoffs.md` publishing every limitation in the README, a repo-level trust pattern the library lacked as a standalone entry.

All four selections passed targeted grep dedup against the live library (details in §2).
